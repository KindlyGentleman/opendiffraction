# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 2.0.x   | :white_check_mark: |
| < 2.0   | :x:                |

## Reporting a Vulnerability

OpenDiffraction is a scientific dataset generator and benchmark toolkit. If you discover a security vulnerability (such as unsafe serialization, path traversal, or credential exposure), please report it responsibly:

1. **Do not** report security vulnerabilities via public GitHub issues.
2. Email maintainers privately or use the GitHub Security Advisory private reporting feature on the repository.
3. Include reproducible steps and the potential impact of the issue.

You will receive an acknowledgment within 48 hours, followed by updates on remediation.

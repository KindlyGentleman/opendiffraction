## Scope of Coverage

This license governs all original scientific dataset artifacts produced by the OpenDiffraction project:

1. **Simulated Scientific Data**: All reciprocal-space diffraction intensity arrays and real-space object transmission arrays.
2. **HDF5 Shard Containers**: `data/train_000.h5`, `data/valid_000.h5`, `data/test_000.h5`, and `data/test_ood_000.h5`.
3. **CXI Standard Files**: `opendiffraction_benchmark.cxi`.
4. **Metadata & Manifests**: `metadata.csv`, `configuration.json`, and all task manifest CSVs (`tasks/T*_manifest.csv`).
5. **Original Visualizations**: All rendered diagrams, contact sheets, and parameter sweep animations in `assets/` and `output/figures/`.
6. **Benchmark Annotations**: Ground-truth task targets and evaluation split assignments.
